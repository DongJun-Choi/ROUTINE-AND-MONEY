# 루틴앤머니 리디자인 캔버스

상태: `초안` — 디자인 검토 중이며 아직 코드에 적용하지 않았습니다.

Stitch 시안(Slate Minimal)을 바탕으로 현재 앱 기능(대시보드, 가계부, 명세서 가져오기, 카테고리)에 맞춰 다시 그린 화면과 디자인 토큰을 모았습니다.

## 이어서 작업하기

- 원본 캔버스: https://claude.ai/artifact/DKV6tqxMhQ2PFNWMPr79Dj
  - 비공개 Artifact라서 소유자 계정으로 로그인해야 열립니다.
  - 화면 수정은 이 캔버스에서 하는 것이 가장 편합니다.
- `canvas/` 폴더는 캔버스 파일의 백업입니다. `.dc.html`은 캔버스 런타임(`support.js`)을 전제로 작성되어, 브라우저에서 단독으로 열면 차트·달력처럼 반복되는 부분이 그려지지 않습니다.
- 캔버스를 다시 고쳤다면 이 폴더도 같은 내용으로 갱신해 주세요.

## 폴더 구성

```text
docs/design/redesign/
├── README.md
├── canvas/               캔버스 원본 백업
│   ├── canvas.json       보드 배치와 제목
│   └── *.dc.html         보드별 화면
└── stitch/               처음 받은 Stitch 시안
    ├── DESIGN.md         Stitch가 만든 디자인 시스템 설명
    └── screen.png        Stitch 대시보드 시안 이미지
```

## 주의할 점

- 화면의 숫자와 가맹점은 모두 샘플입니다. 실제 거래 데이터는 넣지 않았습니다.
- 현재 화면 보드는 `main`(`eb623da`) 기준으로 재현했습니다. 이후 `develop`에 병합된 UI 개편(#6)은 반영되어 있지 않습니다.
- Stitch 시안에 있던 루틴 현황, 예산 소진율, 저축 목표는 지금 데이터 모델에 없어서 리디자인에서 뺐습니다.
- 대비값은 WCAG 기준으로 계산했고, 본문 글자는 라이트·다크 모두 4.5 : 1 이상입니다.
